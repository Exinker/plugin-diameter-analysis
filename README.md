# Diameter Analysis
Плагин для ПО Atom, который строит распределение частиц по диаметру для текущего выбора в таблице анализа.

После запуска плагин получает события из ПО Atom и при изменение текущей пробы и/или спектральной линии загружает данные, пересчитывают и перестраивает гистограмму диаметров вспышек линии.

## Установка
Требуется Python 3.12 и зависимости из `pyproject.toml`.

```bash
uv sync --no-dev
```

## Логи
Плагин пишет диагностический лог в файл `.log` в корне директории плагина.

Для подробной диагностики можно запустить Atom с переменной окружения:
```bash
LOGGING_LEVEL=DEBUG
```

Для headless smoke-проверки:
```bash
QT_QPA_PLATFORM=offscreen uv run pytest tests/test_diameter_gui_smoke.py
```
